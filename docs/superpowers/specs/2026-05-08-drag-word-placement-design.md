# 指定词和位置：词条池拖拽摆放设计

## 背景

当前“指定词和位置”页面的核心方式是点选网格格子后直接输入单词、提示和方向。新的目标是把流程改成先创建词或成语，再把词条拖入网格中摆放。

本设计只覆盖桌面端交互。移动端触控 fallback 暂不纳入本轮实现。

## 用户流程

1. 用户进入“指定词和位置”页面。
2. 页面左侧显示词条池，右侧显示网格。
3. 用户在词条池创建词条。
4. 每个词条必须有词或成语内容，提示可选。
5. 用户选择当前摆放方向：横向或纵向。
6. 用户把词条从词条池拖到网格上的起点格。
7. 系统实时校验是否可以摆放。
8. 合法时放入网格，词条变为已放置状态。
9. 用户可以把已放置词拖到新的网格位置来移动。
10. 用户可以把已放置词拖回词条池来取消放置。
11. 用户点击“开始游戏”时，用当前网格和已放置词生成游戏。

## 状态模型

主状态分成两类：

```ts
type DraftEntry = {
  id: string;
  word: string;
  clue: string;
};

type DraftPlacement = {
  entryId: string;
  row: number;
  col: number;
  direction: 'across' | 'down';
};
```

`grid` 不再作为主状态手动维护，而是由 `entries + placements` 推导：

```ts
grid = deriveGrid(entries, placements, rows, cols)
```

这样拖出词、移动词、删除词条时，只需要更新 `placements` 或 `entries`，网格会重新计算。交叉位置如果仍被其它词占用，字母会保留。

## 网格规则

网格初始状态是全黑。

词条放入后，该词覆盖到的格子自动变成白格并显示字母。未被任何词占用的格子保持黑格。

放置校验包括：

1. 词条不能越界。
2. 同一个词条不能同时存在多个 placement。
3. 新位置上的已有字母必须与当前词条对应字符一致。
4. 移动已放置词时，校验要临时忽略它自己的旧位置。
5. 中文成语按字符数组处理，不能用普通字符串长度假设。

## 拖拽规则

从词条池拖到网格：

- 合法：新增 placement。
- 非法：不放置，并显示冲突原因。

从网格拖到网格：

- 合法：更新该词条 placement。
- 非法：保留原位置，并显示冲突原因。

从网格拖回词条池：

- 删除该词条 placement。
- 词条回到未放置列表。
- 网格由剩余 placements 重新推导。

从网格拖到其它空白区域：

- 不删除、不取消放置。
- 词条自动回到原位置。

删除词条：

- 删除 entry。
- 如果它已经被放置，同时删除对应 placement。

## 页面布局

桌面端采用两栏布局：

- 左侧：词条池。
- 右侧：网格和方向控制。

词条池分两组：

- 待放入：没有 placement 的词条。
- 已放置：有 placement 的词条，显示方向和起点坐标。

词条编辑区：

- 词或成语：必填。
- 提示：可选。
- 添加按钮在词条有效时可用。

网格区域：

- 顶部放方向切换。
- 中间放可拖放网格。
- 底部或右上保留“开始游戏”按钮。
- 拖拽时显示预览，高亮可放置/不可放置状态。

## 反馈和错误

错误信息显示在页面内，不使用 `alert` 作为主要反馈。

常见错误：

- “这个词会超出网格范围”
- “第 3 个字和已有字母不一致”
- “请先添加至少一个词条”
- “请至少放置一个词条”

拖拽预览：

- 合法位置使用当前主题的主色高亮。
- 非法位置使用错误色高亮。
- 不只依赖颜色，旁边同时显示简短文字原因。

## 组件和逻辑拆分

建议新增纯逻辑模块：

```txt
src/ui/game/gridDraftLogic.ts
```

职责：

- `getEntryChars(entry)`
- `deriveGrid(entries, placements, rows, cols)`
- `validatePlacement(entries, placements, candidate, rows, cols)`
- `placeEntry(...)`
- `removePlacement(...)`
- `deleteEntry(...)`

`GridEditorScreen` 负责 UI 状态和事件，不直接手写复杂网格冲突逻辑。

## 测试策略

先写纯逻辑测试：

1. 全黑初始网格。
2. 放入一个横向词后打开对应格子。
3. 放入交叉词且交叉字母一致时合法。
4. 交叉字母不一致时非法。
5. 越界时非法。
6. 移动词时忽略自己的旧位置。
7. 拖回词条池会删除 placement，并保留其它词占用的交叉格。
8. 删除词条会同步删除它的 placement。
9. 中文成语按字符计算长度。

UI 测试/浏览器检查：

- 创建词条。
- 拖入网格。
- 拖回词条池。
- 冲突提示显示。
- 点击开始游戏生成当前谜题。

## 非目标

本轮不做：

- 移动端拖拽 fallback。
- 自动生成布局。
- 自动推荐摆放位置。
- 复杂撤销/重做历史。
- 多选批量操作。

## 已确认的设计决策

本设计已按以下决策固定：

- 网格初始全黑。
- 提示为可选。
- 只考虑桌面端。
- 拖出网格到词条池才取消放置。
- 拖到普通空白区域自动回原位。
